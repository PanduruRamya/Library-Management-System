# Library-Management-System

A comprehensive and user-friendly **Library Management System** designed to automate and streamline the daily operations of a library. This application helps librarians efficiently manage books, student records, and transaction histories.

---

## 🚀 Features

* **Book Management:** Add, update, search, and delete books from the library catalog.
* **Member Management:** Register and manage library members (Students/Teachers).
* **Issue & Return Track:** Track borrowed books, set return due dates, and calculate fines for late returns.
* **Search Functionality:** Instantly search for books by Title, Author, or Category.
